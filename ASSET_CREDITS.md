## Usage notes

- No branded cigarette-pack photography is intentionally mapped to a product brand.
- The `resmi bal` asset is a plain/generic tobacco package image; it is not used as a representation of any product brand.
- The catalog must preserve the product's own image field when a genuine first-party image is available. The fallback configuration is intended only for missing/placeholder imagery.
- For CC BY-SA assets, retain this credit file with the repository and preserve the applicable license terms if the asset is modified or redistributed.
